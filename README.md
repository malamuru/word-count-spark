## ✨ Overview

This repository contains a collection of projects demonstrating **cloud computing and big data processing** using AWS and Apache Spark.

The projects showcase practical implementations of:
- Distributed data processing using PySpark  
- Cloud deployment using AWS EC2 and Docker  
- Serverless ETL pipelines using AWS Lambda  

---

## 🚀 Projects Included

---

### ⚡ Project 1: Word Count using PySpark on AWS

#### 📌 Description
A distributed word count application that processes text data stored in **AWS S3** using **Apache Spark**.

#### 🔧 Features
- Reads data from S3  
- Processes text using Spark transformations  
- Generates word frequency counts  
- Stores output back in S3  

---

### 🐳 Project 2: Node.js Web Server Deployment using Docker

#### 📌 Description
A simple Node.js web application containerized using Docker and deployed on AWS EC2.

#### 🔧 Features
- Lightweight Express server  
- Docker containerization  
- Deployment on EC2 instance  
- Accessible via public IP  

---

### ⚙️ Project 3: Serverless ETL Pipeline using AWS Lambda

#### 📌 Description
A serverless pipeline that processes CSV data uploaded to S3 using AWS Lambda.

#### 🔧 Features
- S3-triggered Lambda execution  
- Data cleaning and transformation  
- Output stored in destination bucket  
- Logging via CloudWatch
